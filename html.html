🔧 راهنمای اتصال به Supabase (رایگان و دائمی)

برای اینکه اطلاعات برای همیشه ذخیره شود و همه بازاریاب‌ها به آن دسترسی داشته باشند، باید یک حساب رایگان در Supabase بسازید و کلیدهای آن را در کادرهای زیر وارد کنید.

۱
ساخت حساب رایگان به سایت supabase.com بروید و با ایمیل خود ثبت‌نام کنید. سپس یک پروژه جدید بسازید.
۲
ساخت جدول‌ها در پنل Supabase، به بخش SQL Editor بروید، روی New Query کلیک کنید و کد SQL پایین این صفحه را کپی و Run کنید.
۳
کپی کلیدها به مسیر Project Settings → API بروید. دو مقدار Project URL و anon public key را کپی کنید.
۴
وارد کردن در کادرهای زیر کلیدها را در فرم زیر وارد کنید و دکمه "ذخیره و تست اتصال" را بزنید.

🔑 ورود کلیدهای اتصال

📋 کد SQL برای ساخت جدول‌ها (یک بار اجرا کنید)

این کد را در SQL Editor کپی و Run کنید:

create table if not exists customers (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz default now(),
  name text, phone text, org text, owner text, status text, note text
);
create table if not exists followups (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz default now(),
  title text, customer_name text, assignee text,
  followup_date date, priority text, note text, completed boolean default false
);
alter table customers enable row level security;
alter table followups enable row level security;
create policy "Public Access" on customers for all using (true) with check (true);
create policy "Public Access" on followups for all using (true) with check (true);
